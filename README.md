## 🎯 프로젝트 소개


사용자가 언제 어디서나 원하는 책을 쉽고 빠르게 찾고, 즐길 수 있도록 하는 **인터넷 서점 플랫폼**입니다.

---

### 🚀 핵심 기능

#### ❗️ 찾는 책이 있다면?   -> **검색기록, 추천 검색, 고급 검색**을 활용한 **효율적인 검색 제공**

#### ❓ 찾는 책이 없다면?   -> **장르 필터, 댓글, 별점, 다양한 정렬** 기능으로 **새로운 책을 편리하게 탐색**

####  ✅ 언제나, 어디서나!        ->  **Android, iOS, 데스크탑** 모두에서 사용 가능 – 크로스플랫폼 지원 완비

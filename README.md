## 🎯 프로젝트 소개

사용자가 언제 어디서나 원하는 책을 쉽고 빠르게 찾고, 즐길 수 있도록 돕는 서비스입니다.  
본 프로젝트는 **직관적인 UI/UX**, **강력한 검색 기능**, **개인 맞춤형 추천 시스템**을 통해 사용자 경험을 극대화합니다.
